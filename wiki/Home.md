# AMN Healthcare Modern Data Platform Wiki

Welcome to the **AMN Healthcare Modern Multi-Cloud Data Platform & Analytics Engineering Wiki**.

> **⚠️ Learning Project Disclaimer:**  
> This project is a hands-on **educational data engineering case study** inspired by Snowflake's public AMN Healthcare customer story. All datasets are synthetic, simulated, or public reference data (CMS). Published metrics (>100 GB/day, 1,176 tables, 99.9% SLA, 93% cost reduction) are reference benchmarks and architectural design goals, not claims of AMN Healthcare's proprietary systems.
