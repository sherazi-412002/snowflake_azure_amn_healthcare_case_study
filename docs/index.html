The Challenge

Healthcare staffing data was
broken & slow

AMN Healthcare managed staffing data across multiple disconnected systems. Finance waited 3 days for payroll reports. Operations had no real-time visibility into hospital fill rates. Decisions were made on stale spreadsheets.

⏳
3-day reporting lagPayroll & staffing reports ran weekly, manually extracted from 3 systems
🗂️

🔧
Manual, error-prone ETLData engineers spent hours on one-off scripts with no audit trail
📉
No executive visibilityLeadership could not track KPIs like fill rate or cost-per-placement in real time

A fully automated, metadata-driven pipeline moves data from raw landing zones through transformation layers to executive-ready dashboards — with zero manual intervention.

🏅 Bronze / Silver / Gold

Three-layer Snowflake schema — raw ingestion, cleaned/conformed, and business-ready mart tables with full audit trail on every record.

⚡ Event-Driven Ingestion

ADF File Event Router triggers pipelines automatically when files land in ADLS. No schedules, no polling, no manual kicks.

🔑 Metadata-Driven Config

A single Snowflake control table drives which files get ingested into which tables — add a new data source with one row.

🔒 Enterprise Security

All secrets in Azure Key Vault. RBAC on every resource. Full Terraform IaC — reproducible and auditable infrastructure.
